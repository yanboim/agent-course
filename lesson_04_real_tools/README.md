# 第 4 课：真实工具 —— 文件 / 命令 / HTTP + 安全与错误处理

## 知识点清单

1. **模型输出永远不可信**：它可能给出 `../../etc/passwd`、`rm -rf`、
   非 https 链接。安全边界必须由**代码**强制，不能靠 prompt 恳求
2. **路径监狱（jail）**：resolve 后检查是否仍在沙盒目录内，
   越界一律拒绝（任务 2 现场演示被拦）
3. **命令白名单**：`shlex.split` + `shell=False` + 白名单 + 超时 + cwd 钉死
4. **工具永不抛异常**：一切错误转成 `ERROR: ...` 文本作为 tool 消息回传，
   模型读到错误会调整策略 —— 这是 Agent 韧性的来源
5. **返回值一律字符串 + 截断**：防止一个巨大输出撑爆上下文

## 运行

```bash
cd lesson_04_real_tools
python 01_real_tools.py     # 任务1正常干活；任务2演示越界被拦+自我纠正
```
