# 第 5 课：Memory —— 上下文管理：裁剪、摘要压缩、长期记忆

## 知识点清单

1. **token 贪食蛇问题**：Agent 每轮全量重发历史 → prompt token 线性暴涨
   （钱）+ 终会撞上下文窗口上限（崩）
2. **滑动窗口**：只留最近 K 条。便宜、简单，但**失忆**：被裁的不是垃圾
   是记忆 —— 01 例现场演示翻车
3. **摘要压缩**：老对话先压成摘要再丢弃原文。省钱且保住关键事实，
   但有损 + 摘要调用本身要花钱
4. **长期记忆（思想）**：关键事实抽成键值对存外部（文件/数据库），
   需要时检索注入上下文 —— RAG 的思想用在"记忆"上
5. 完整记忆架构 = 短期（原文最近几轮）+ 中期（滚动摘要）+ 长期（外部存储）

## 运行

```bash
cd lesson_05_memory

```
